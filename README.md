# ShareSign for Claude

Prepare contracts for e-signature, find evidence in virtual data rooms, and review signing progress in the same conversation. ShareSign combines electronic signatures and secure data rooms for founders, advisers and teams.

## Tasks

- **Prepare an agreement:** “Prepare an offer-letter draft from my template for my review.” Ask only for missing recipient details and essential terms, then return an unsent draft and readiness checklist.
- **Research a room:** “Find the change-of-control clause in our due-diligence room and cite the pages.” Identify the evidence and disclose files that could not be searched.
- **Business brief:** “What is awaiting signature, and what needs attention?” Separate drafts, sent agreements and completed documents, with source links.
- **Viewer activity:** “Who has opened the pitch deck?” Requires its own approved permission; observed activity does not establish investor intent.

## Connection

The bundle includes five skills and one remote production MCP server at https://sharesign.co/mcp. It runs no local server, hooks or executables and contains no credentials. Start with **Get started**, use the host's actual sign-in flow, then select your business and permissions in ShareSign. A fresh context read confirms the connection. Do not paste passwords or codes into chat.

ShareSign Pro and Business include assistant access, including active qualifying partner offers. Other founders can use normal setup at https://sharesign.co and optional fictional examples at https://sharesign.co/examples. No fundraising onboarding is required.

Read-only consent remains useful. Preparing drafts, searching file contents and individual viewer activity each require additional permission. This bundle does not send or sign agreements, publish or invite to rooms, file signed copies, issue shares, calculate valuations or change your billing. Review and send in ShareSign.

## Privacy and recovery

Choose the business and access deliberately. Document search can return excerpts; analytics can return individual viewer activity. Information received by Claude is also subject to your Anthropic settings. Revoking ShareSign access blocks future retrieval; it does not remove previous conversation content. Installation or upgrade does not expand an existing grant.

If tools are unavailable, distinguish incomplete dependency loading from login failure. Use the host's actual connection controls and the [connection guide](https://sharesign.co/docs/connect#agents). Duplicate custom connectors must not be mixed with this plugin. Do not remove your existing connector until the intended production connection has been verified.

A saved unsent draft survives an interrupted conversation. Retry the same operation with the same idempotency key and inputs. A changed recipient needs a fresh version and deliberate edit. New conversations do not yet support server-side lookup of prior preparation operations; use the saved draft link.
