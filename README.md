# ShareSign for Claude

Unpublished candidate 0.1.7. Its public installation and extra-permission recovery remain unverified.

Prepare agreements and private data-room plans, research due diligence with citations, review recorded ownership and hypothetical rounds, and find the next blocker across closings, deals, funds, cohorts and clients.

Use the existing ShareSign connector at `https://sharesign.co/mcp`. Choose the business and individual permissions for your task. Existing permissions do not grow automatically; review fresh consent only when the required permission is missing. Do not add a second custom connector merely to use another ShareSign task.

## Choose a task

- Prepare a room: tailor the folders and diligence checklist, then open the saved proposal in ShareSign for deliberate private creation.
- Research diligence: ask for clauses with file/page citations, or review outstanding requests and question statuses with explicit coverage.
- Review a cap table: read recorded ownership, supply valuation/investment/currency/pool assumptions and compare a hypothetical financing scenario. Source facts and recorded changes are reviewed in ShareSign.
- Prepare an agreement: use an approved template or supplied terms, review the unsent draft and correct precise fields while preserving their identities. Signatures and sending remain yours to confirm in ShareSign.
- Review business work: inspect separately approved closing, deal, fund, cohort or client blockers with source links. Prepare the next step before acting on it yourself.

Each skill reads the declared connection's approved business and current effective permissions before connected work. A signing brief from terms supplied in chat can be prepared without a ShareSign connection; it reads and saves no records.

## Connect deliberately

Choose the business and each needed permission in ShareSign's actual consent screen. The `.mcp.json` file declares the existing `https://sharesign.co/mcp` server. An existing classic connection cannot gain new permissions by refreshing. A browser workspace change does not switch the assistant's approved business. Current role, plan and feature access remain authoritative.

Use the host's real connection controls for authentication or reconnection, then reread context once. ShareSign Settings, Assistants identifies and disconnects existing approvals; it does not edit their permissions. Optional permissions can be declined. Keep a useful permitted task rather than looping through setup. Never paste passwords or one-time codes into chat.

## Recover saved work

Retain the saved operation or proposal ID and recover that exact result after interruption. A successful proposal is not a created room; an unsent draft is not a sent agreement; a hypothetical round is not recorded equity. Use the returned authenticated review/source link for the deliberate next step. An expired or deleted result must not be replaced silently.

## Installation and availability

Use ShareSign's official Claude directory listing. In Claude Code, install the published package:

```sh
claude plugin install sharesign@anthropic-plugin-directory --scope local
```

This command installs the directory's published package, not this local candidate. The directory serves its published version, which may differ from this source. A source push or successful scan is not proof that a candidate is publicly available or verified on every Claude surface. Check the installed version and declared resource before following this source's expanded tasks.
